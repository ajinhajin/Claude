# 내 손글씨 폰트 만들기 (한글 · 영문 · 숫자)

손글씨로 템플릿을 채워 스캔하거나 사진을 찍으면 **TTF 폰트**를 만들어 줍니다.

- 한글 **11,172자 전부**를 만듭니다. 음절을 하나하나 쓰는 대신 자모를 위치별로 한 번씩만 쓰면 자동으로 조합합니다.
- 영문 대·소문자, 숫자, 키보드 문장부호 전부와 `“ ” ‘ ’ … · ₩`를 지원합니다.
- 휴대폰 사진도 됩니다. 기울기·원근·그림자를 자동으로 보정하고, 페이지 순서와 방향(거꾸로 찍어도 됨)도 자동으로 인식합니다.

## 1. 템플릿 인쇄

`templates/` 폴더의 PDF 중 하나를 A4에 인쇄하세요. 배율은 달라도 괜찮습니다.

| 템플릿 | 페이지 | 한글 칸 수 | 설명 |
|---|---|---|---|
| `template_full.pdf` | 6장 | 183칸 | **권장.** 받침 있는/없는 글자 모양을 모두 직접 씁니다 |
| `template_quick.pdf` | 4장 | 105칸 | 받침 있는 모양은 받침 없는 모양을 눌러서 자동으로 만듭니다 |

두 템플릿 모두 영문·숫자·기호 101칸이 포함됩니다.

> 태블릿 사용자는 `template_*_pN.png` 이미지를 노트 앱(GoodNotes, 노타빌리티 등)에서 열어 그 위에 쓰고, 이미지로 내보내도 됩니다.

## 2. 손글씨 쓰기

- **검은색 펜**(0.5~0.7mm 중성펜이나 사인펜)을 쓰면 가장 깔끔하게 인식됩니다. 연필은 옅어서 인식이 잘 안 될 수 있습니다.
- 칸마다 **위 라벨에 적힌 글자만** 쓰세요.
- **한글 칸**
  - 칸 하나가 글자 한 자의 전체 크기입니다. 회색으로 연하게 보이는 예시 글자에서 **라벨의 자모가 들어갈 자리에만** 쓰세요.
    - 예: 라벨이 `ㄱ · 간`이면 `간`의 `ㄱ` 자리에 `ㄱ`만 씁니다.
    - 예: 라벨이 `ㅏ · 안`이면 `ㅏ` 자리에 `ㅏ`만 씁니다.
  - 적힌 위치 그대로 조합에 쓰이므로, 같은 종류의 칸끼리는 **크기와 위치를 비슷하게** 맞춰야 결과가 좋습니다.
- **영문 칸**: 굵은 선이 기준선(baseline)입니다. 위쪽 실선은 대문자 높이, 점선은 소문자 높이, 아래쪽 선은 g·j·p·y 같은 글자의 꼬리 위치입니다.
- 쓰지 않은 칸은 폰트에서 빠집니다. 한글 자모 칸이 비면 그 자모가 들어가는 음절을 만들지 못합니다.
- 회색 글자와 안내선은 스캔할 때 자동으로 지워집니다.

## 3. 스캔 / 촬영

- 스캐너나 스캔 앱(휴대폰 기본 문서 스캔, vFlat, CamScanner 등)을 추천합니다.
- 일반 사진으로 찍어도 됩니다. **네 모서리의 검은 사각형이 모두** 보이게 찍고, 밝은 곳에서 그림자가 지지 않게 찍어 주세요.
- 파일 형식은 JPG, PNG, PDF를 쓸 수 있습니다. PDF를 쓰려면 `pip install pymupdf`가 필요합니다.

## 4. 폰트 만들기

```bash
pip install -r requirements.txt

python build_font.py scans/*.jpg --name "MyHandwriting" --name-ko "내손글씨"
```

결과물은 `out/` 폴더에 생깁니다.

```
out/MyHandwriting.ttf     ← 설치해서 쓰면 됩니다
out/MyHandwriting.woff2   ← 웹용 (brotli가 설치된 경우에만 생성)
out/preview.png           ← 미리보기
out/cells/                ← 칸별 인식 결과 (확인·수정용)
```

실행하면 이렇게 출력됩니다.

```
1) 스캔 이미지 인식
  ✓ IMG_0001.jpg: full 1/6 페이지, 52/52 칸 인식
  ...
3) 폰트 생성
  영문·숫자·기호 101자, 한글 자모 51자, 한글 음절 11172/11172자
```

### 옵션

| 옵션 | 설명 |
|---|---|
| `--threshold 0.65` | 글씨가 흐리거나 끊겨서 나올 때 올립니다 (기본 0.55). 잡티가 많이 생기면 내립니다 |
| `--weight 1` / `--weight -1` | 획을 굵게 / 가늘게 보정합니다 (px 단위) |
| `--hangul-width 950` | 한글 글자 폭을 바꿉니다. 작을수록 자간이 좁아집니다 (기본 1000) |
| `--space 250` | 띄어쓰기 폭을 바꿉니다 |
| `--overrides fix/` | 특정 칸의 이미지만 바꿔 끼웁니다 (아래 참고) |

### 일부 글자만 다시 쓰기

1. `out/cells/`에서 마음에 들지 않는 글자의 이미지를 찾습니다.
   - 파일 이름 예: 영문 `A` → `uni0041.png`, 초성 `ㄱ`(ㅏ형·받침없음) → `cho00.V0.png`
2. 그 이미지를 `fix/` 폴더에 복사한 뒤 그림판 등으로 고칩니다. 흰 바탕에 검은 글씨로, 칸 전체 크기를 유지해야 합니다.
3. `--overrides fix/` 옵션을 붙여 다시 실행합니다.

템플릿 한 장만 새로 써서 다시 스캔해도 됩니다. 여러 파일에 같은 칸이 있으면 **나중에 넣은 파일**의 글씨가 쓰입니다.

## 동작 원리

```
템플릿 인쇄 → 손글씨 → 스캔/사진
   → 모서리 표식으로 원근 보정, 상단 표식으로 페이지 식별 (handfont/scan.py)
   → 조명 보정 후 잉크만 추출해 칸별로 자르기
   → potrace로 벡터 윤곽선 변환 (handfont/vectorize.py)
   → 한글 음절 = 초성 + 중성 + 종성 조합(TrueType 컴포지트 글리프) (handfont/build.py)
```

한글 자모는 모음 모양에 따라 위치가 달라서, 다음과 같이 나눠서 씁니다.

| 구분 | 변형 | 예시 |
|---|---|---|
| 초성 19자 | ㅏ형 / ㅗ형 / ㅘ형 × 받침 없음·있음 = 6벌 | 가·간 / 고·곤 / 과·관 |
| 중성 21자 | 받침 없음 / 있음 = 2벌 | 아 / 안 |
| 종성 27자 | 1벌 | 각, 갃, 간 … |

## 파일 구성

```
make_template.py        템플릿 생성 (templates/ 를 다시 만들 때)
build_font.py           스캔본 → 폰트
handfont/charset.py     글자 목록, 자모 변형 정의
handfont/layout.py      페이지·칸 좌표
handfont/template.py    템플릿 그리기
handfont/scan.py        스캔 인식 (원근 보정, 칸 추출)
handfont/vectorize.py   비트맵 → 벡터
handfont/build.py       TTF 조립
tests/simulate.py       가상 손글씨 사진으로 전체 과정 테스트
```

전체 과정을 테스트하려면 다음을 실행합니다 (Linux, 나눔펜 폰트 필요).

```bash
python tests/simulate.py --preset full -o /tmp/sim
python build_font.py /tmp/sim/*.jpg -o /tmp/sim/out
```
